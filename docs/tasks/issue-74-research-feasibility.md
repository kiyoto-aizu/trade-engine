# Issue #74 レンジ・反発戦略研究: 事前仕様案とデータ点検

作成: 2026-11-23 JST / Task ID: TRD-074

## 背景と目的

#73 の短期押し目買いと独立に、横ばい相場のレンジ取引と下落後の反発狙いを研究する。30万円の共通資金・枠を使った並行運用について、単独運用に対する売買頻度、コスト後損益、リスク、日次損益の連動を比較する。分散効果や収益性は前提としない。実売買、実発注、本番設定変更、追加課金は対象外。

## 作業計画

1. #71・#73 の既存研究と利用可能なデータ、未使用期間を点検する。
2. 結果を見る前に下記の候補仕様をレビューし、未決事項を確定して版・実装・入力を固定する。条件変更は別試行として記録し、試行数を報告する。
3. 時点整合した母集団・市場営業日・足・価格調整基準を検査する。欠落を別日や現行マスタで補わず、母集団欠測日と候補ゼロ日を区別する。
4. 戦略ごとの独立口座と、押し目＋レンジ、押し目＋反発の共通口座を同じ期間で再計算する。単独成績の足し算を共通口座の成績とみなさない。
5. 集計・感度・期間別の不確実性を報告し、未使用の前向き期間で追検証する。採用は人が判断する。

### 共通データと候補

- 各シグナル日引けまでに利用可能な情報のみを使用し、翌市場営業日の始値で仮想買付。ただし既存DBの調整済み値は取得時版を復元できず、後日訂正の影響も不明。既存の4桁マスタは後日の情報や廃止漏れが混入し得るため、完全な時点整合・生存者バイアスなしとはいえない。別日マスタで欠落を補わない。#73 r4 の普通株・市場の判定案は未承認であり、本探索では適用しない。
- #73 `signal_only` と同一の既存DB母集団・順位付けを使う。マスタ上場期間とコード末尾0、シグナル日生終値1,000円以下、当日を含む有効足20本の売買代金平均1億円以上。欠損と不足足の扱いは既存パネルの計算に従い、取引停止等をまたぎ得る。合成順位50位まで同順位を含む。各戦略の同日優先順は合成順位、コード昇順。
- 押し目は #73 `signal_only` の「1足リターン−2〜0%両端込み、5足リターン>0、60足高値からの乖離≥−5%」と上位50位を比較用の出発点とする。ただし同一母集団・同一期間で再計算し、既存542件を比較結果として流用しない。既存研究と異なる母集団や執行を使う場合は別基準と明記する。
- レンジ: 20足リターンの絶対値≤3%、当日終値が25足平均を2%以上下回る。反発: 20足リターン≤−10%、5足リターン≤−8%、1足リターン>0。いずれも当日までの調整済み終値を使用。既存パネルの有効足窓を使い、必要値欠測は候補外。既存パネルの25足平均は履歴が25足未満でも得られる部分平均を使う。これは下降や横ばいの代理であり、真の市場状態の証明ではない。共通順位は当日リターン降順を含み、上昇日の反発は押し目より相対的に有利になり得るが、売買代金順位との合成結果に依存する。
- 例示閾値を成績で修正しない。指標が揃わない銘柄は条件不一致と区別して数える。#73 の探索を見た後に立てた案なので、全期間で独立仮説とみなさない。

### 資金・執行・並行運用

- 初期資金30万円、同時保有3枠、100株単位、注文上限20万円、前日引け資産の1/3を1枠の基本上限、現金・買付費用を考慮。往復コストの基準は片道0.105%。買い時に同日引け売却予定の枠・資金を先取りしない。
- 押し目は損切りなしで #73 と同じ買い日を1日目とする第3市場営業日引け決済。レンジ・反発は同じ予定決済に加え、予定決済日より前の終値が買値比−5%以下の場合は翌営業日寄りの売りを予約する。この非対称によりシグナルと出口の効果は分離できない。寄値欠測・非正なら予約を保持し最初の有効な寄値まで待つ。予定決済日には、既存の予約がなければ有効終値で決済し、欠測なら次の有効終値まで待つ。ギャップや停止で−5%通りの約定は保証されない。
- 共通口座は同時注文時に押し目を優先し、残りをもう一方の戦略に割り当てる。同一銘柄の複数候補は優先順位順に処理し、既保有なら見送る。押し目優先は相手戦略に不利となり得るため、別の優先順を調べる場合は別試行とする。
- 価格足は仮想約定であり実約定ではない。寄り・引けの時刻、板、出来高、呼値、価格制限、停止を日足だけで確認できない。感度は片道コストを0.105%・0.205%・0.305%で再計算し、価格・数量の変化を含める。分足による時刻確認、実呼値に基づく丸め、停止・ストップ価格で約定不可とする感度は本試行では未実施と報告する。実勢スプレッドや約定可能性の証明とはしない。
- 未決済・欠損は架空の決済や補間を行わず、理由・枠占有・最終評価額を報告。最終観測値評価とゼロ評価ストレスを分け、未決済を完了約定の期待値に含めない。過去価格の持ち越しを使う評価は、その古さを併記する。

### 指標と比較

- 各戦略・各口座で候補、資金・枠制約後の新規買付、完了約定、保有中・未決済、右打ち切り、欠測・見送り理由を分ける。全営業日を分母とした週・月の頻度、勝率、完了約定のネット期待値・中央値・分布、資産と現金、含み損益、最大DDと稼働率を報告。期間別と相場状態別も表示する。
- 独立した単独口座の日次時価評価損益について、全営業日（不取引日を含む）と、両戦略が同時に保有する営業日を分け、母数と相関を報告する。ゼロ分散・不足時は算出不能とする。共通口座の戦略別日次損益は保有・売却・費用を帰属させ、全口座の資産変化と突合する。
- 同時新規買付日、同時保有日、同時損失日、共通銘柄・シグナル日の重複を別々に数える。同時損失率は両戦略保有日を分母とし、別途全営業日分母も示す。急落日の指数・閾値・時点と欠測処理を事前固定し、日数と同時損失率を示す。状態分類は本番 MarketRegime ではなく使用した代理指標を明記する。
- 対照には同じ資金ルールの押し目単独と現金保有を含める。状態別・期間別の標本数を示す。連続ブロック区間推定は未実施の場合にそのまま報告し、統計的な優位と断定しない。少数標本、探索・複数比較、保有依存、非定常性により確実な将来予測とはしない。

## 現時点の不足と次の作業

全営業日の時点付き母集団、対象期間の公式市場営業日、比較に必要な足と調整版の完全性、執行感度に必要な時刻・呼値等を確認できていない。50日の偏ったパイロットを全期間に補完すると比較が歪む。以下の v1 は #73 と同じ不完全な母集団に限定した探索であり、これらの不足を解決した検証ではない。

次は、既存契約・保存境界・他セッションの期間使用を確認し、未決の評価条件を固定する。全営業日の時点マスタ等を安全に確保・検査できなければ、不足日と取得可否を報告し、条件に応じた探索にすり替えない。新規の将来期間を確保する場合も #73 と独立性・干渉を確認してから開始する。第三者レビューは判定基準・運用判断に該当するため想定するが、依頼とレビュー用ラベルの変更はユーザーからの依頼時のみ。

続行条件は、時点別母集団・営業日・価格版の完全性と取引可能性の不足を解決でき、比較仕様・試行数・終了条件と未使用期間を事前固定できること。いずれかが確認できなければ採用判断や独立検証を保留し、結果に合わせた閾値調整はしない。追加の探索が必要な場合は別試行・別途判断とし、事後的に採否の数値閾値を設けない。
