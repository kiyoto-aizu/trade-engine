# scripts の用途

- `tasks/`: 定期タスクの登録と実行入口
- `analysis/`: 読み取り中心の分析・調査ツール
- `ops/`: 非常停止などの運用操作
- `common/`: スクリプト共通処理

`tasks/` の起動スクリプトはWindowsタスクスケジューラから参照されます。移動時は登録済みタスクのアクションも更新してください。

## Webhook経由のIssue作成

`new-issue.ps1` はリポジトリ直下の `.env` に設定した
`ISSUE_CREATION_WEBHOOK_SECRET` を使います。`.env` と本文ファイルはUTF-8で保存してください。
日本語コメントを含むスクリプト自体は、Windows PowerShell 5.1でも正しく読み込めるよう
**UTF-8 BOM付き**で保存してください。

```powershell
.\scripts\new-issue.ps1 `
  -Title "TRD-PR3.2 dry run" `
  -BodyFile ".\issue.md" `
  -Labels plan-ready,jquants `
  -Assignees kiyoto-aizu `
  -DryRun
```

`-DryRun` もWebhookへリクエストを送信するため、シークレットの設定が必要です。
`-DryRun` を省略すると実際にIssueを作成します。

Windows PowerShell 5.1では `Get-Content` の戻り値にパスやドライブの付加情報が含まれます。
JSON変換が付加情報までたどらないよう、本文は `[string]` 型の変数で受け取ります。
HTTP送信には .NET の `System.Net.Http` を使い、Windows PowerShell 5.1でも型を解決できるよう
スクリプト内で `Add-Type -AssemblyName System.Net.Http` により読み込みます。
